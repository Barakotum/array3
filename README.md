# array3

Програма демонструє роботу з динамічним вектором цілих чисел.

У програмі реалізовано:
- введення цілих чисел з консолі;
- пошук мінімального та максимального значення;
- ділення кожного елемента на середнє значення;
- множення кожного елемента на середнє значення;
- обчислення квадратного кореня кожного елемента.

## Збірка

```bash
g++ array3.cpp tk1.cpp tk2.cpp tk3.cpp tk4.cpp tk5.cpp -o array3
